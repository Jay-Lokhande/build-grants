# Contributing

Add rows to [README.md](README.md) and [data/grants.json](data/grants.json).

- **Official URL** on the organization’s domain (or canonical GitHub org)
- Category: `infrastructure`, `security`, `mozilla`, `protocol`, `fellowship`, `vendor`
- **No** pay-to-apply or affiliate links
- Tuition scholarships belong in [oss-programs scholarships](https://github.com/Jay-Lokhande/oss-programs-and-hackathons/blob/main/programs/scholarships.md), not here
